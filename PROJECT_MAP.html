تست معمولی Quick check

بعد از هر تسک · حدود ۱ دقیقه
pnpm check
  • lint + typecheck + unit tests
  • آخرش باید همه سبز باشد، بدون ✗

تست کامل Full check

قبل از merge یا آخر هر مسیر · چند دقیقه
pnpm check:all
  • همان چیزی که GitHub CI اجرا می‌کند: فرمت، lint، تایپ، تست، build و تست مرورگر (e2e)
  • بار اول یک‌بار لازم است: pnpm --filter @vorchain/web exec playwright install chromium

دیدن سایت See it

از مسیر اسکلت سایت (P1-12) به بعد
pnpm dev
  • بعد در مرورگر: http://localhost:3000
  • برای بستن: Ctrl + C
